# Huedays legal pages

Public privacy policy and terms of use for the Huedays app, served at [noelecatbed.github.io/huedays-legal](https://noelecatbed.github.io/huedays-legal/). Text comes from the app’s `documents.ts`. The published pages omit paid-only sections (Purchases, Pro) because v1 ships free.

Regenerate after updating `documents.ts`:

```
node generate.mjs
```

Pass `--paywall` to include the paid sections. GitHub Pages is served from the `main` branch root.
